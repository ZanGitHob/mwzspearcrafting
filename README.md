# Mowzie's Mobs Spear Recipe

One day I was playing old Mowzie's Mobs mod, I stumbled upon a group of Barakoas (Is this the plural?) and I saw Barakoana is wielding a long-reaching spear. I thought, "Why can't I make that early-game?" I wanted it so bad that I scrambled this quickly.

The recipe is a shapeless 1 flint, 2 sticks, and a string.

---
## Dependencies

Mod Loader: Forge 1.10.2 (12.18.3.2422).
Dependencies: Mowzie's Mobs (mc1.10.2, v1.3.2)

---

## What is inside the JAR?

Fear not, my friend! Nothing harmful is inside.

```
src/main/
├── java/com/spearrecipe
│   └── SpearRecipeMod.java
└── resources/
    ├── mcmod.info
    └── assets/
```

---

## Installation Guide

1. Download the `.jar` file.
2. Open any ForgeModLoader-ready launcher (preferably MultiMC or PrismLauncher).
3. Drop the file into `mods/` folder in an instance.
4. Open Minecraft.
